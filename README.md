# Mining Trends · 1950–2025

Interactive charts of Australian metal mining industry trends.

## How to update the charts

The chart code lives in `src/App.jsx`. When Claude gives you an updated version:

1. Go to your GitHub repo
2. Click into `src/App.jsx`
3. Click the pencil (edit) icon, top right of the file
4. Select all (Ctrl+A / Cmd+A), paste the new code
5. Scroll down, click "Commit changes"
6. Vercel auto-deploys in ~60 seconds

That's it.

## Running locally (optional)

If you ever want to preview before pushing:

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Build

Vercel runs `npm run build` automatically. You don't need to do this yourself.
